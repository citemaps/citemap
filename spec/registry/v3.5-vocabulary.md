# citemap.json v3.5 Recommended Values Registry

> Vocabulary for `brand.taxonomy`, `@graph` / `relationships[]` edge and node types, and the enumerations defined in [v3.5](../v3.5.md). Versioned independently of the spec.

**Registry version:** 2026-11
**Spec version:** 3.5
**Status:** Living document
**License:** MIT

---

## What changed from v3.4-vocabulary

Registry `2026-06b` (v3.4) carries forward with these changes. Strictly additive: nothing is removed.

- **16 edge types** graduate from the extension namespace (`https://citemaps.org/ext/v1/types/{name}`), which stays valid as an alias.
- **Node types** for brands, products, channels and media.
- **Enumerations** for the fields v3.5 defines (trust tiers, event types, lifecycle, corroboration, business relationships, Media).
- The four v3.3 vertical aliases move from "dual-write" to **deprecated**: producers MUST stop emitting them; readers and validators keep accepting them with a warning.

Producers authoring against this registry SHOULD set `brand.taxonomy.taxonomyVersion` to `"2026-11"`.

## `entityType`, `organizationType`, `primaryVertical`, `modifiers`

Carried forward from [v3.4-vocabulary](./v3.4-vocabulary.md) unchanged: the same 29 Tier 1 and 17 Tier 2 verticals, the same retired values, the same modifiers.

### Aliases (deprecated in 2026-11)

| Legacy name | Canonical name |
|---|---|
| `legal` | `legal-services` |
| `financial` | `financial-services` |
| `events` | `events-venue` |
| `research` | `science-research` |

v3.4 scheduled these for removal at v3.5. They are deprecated instead, so documents that carry them keep validating ([v3.5 §12](../v3.5.md#12-deprecations)). Producers MUST NOT emit them in new documents. Validators SHOULD warn and MUST NOT reject.

## Edge type vocabulary

Each type's URI is `https://citemaps.org/v3.5/types/{type}`. For the types marked *ext*, `https://citemaps.org/ext/v1/types/{type}` is the same type ([v3.5 §3.2](../v3.5.md#32-short-names-and-extension-urls-are-the-same-type)).

## Deprecation log

### 2026-11 (v3.5 release)

- Vertical aliases `legal`, `financial`, `events`, `research`: deprecated (were dual-written through v3.4).
- `publications[].contentType` `podcast`, `video`, `testimonial`, `award` for new entries: deprecated.
- No removals.

### 2026-06b (v3.4 release)

No deprecations.

### 2026-06 (v3.3 release)

Four renames and four retirements per the v3.3 deprecation log.
